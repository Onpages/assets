# Onpages/assets — публичное зеркало ассетов производства

Назначение: постоянные URL графических ассетов AI-фильмов (референсы для агента-генератора,
канал `input_urls`). Хранилище «тупое»: только файлы-байты; вся логика и реестр — в
приватном репо проекта.

**Владелец и правообладатель: Евстафьев Николай (Onpages), 2026. Все права защищены.**
Использование, копирование и переиспользование материалов — только с письменного
разрешения правообладателя.

## Правила ведения (commit-only)

1. В репозитории ТОЛЬКО изображения-ассеты. Никаких документов, промптов, токенов,
   доступов и служебных файлов — публичное репо не отозвать (форки и кэш остаются).
2. Опубликованный файл НЕ переименовывается и НЕ перезаписывается: новый контент = новый
   файл (`..._v2.png`) + запись в реестре проекта. Манифесты сессий ссылаются на URL —
   смена содержимого под тем же адресом ломает их тихо.
3. Формат URL: `https://raw.githubusercontent.com/Onpages/assets/main/<фильм>/<тип>/<файл>`.
4. Файлы — ASCII-имена, PNG (ассеты со стилем/прозрачностью) без пережатия.
5. Реестр ассетов (asset_id → URL → версия → статус) ведётся в приватном репо проекта,
   здесь — ни реестра, ни описаний производства.

## Структура

```
<фильм>/
  caps/        листы персонажей (капты: развороты, эмоции, позы)
  plates/      пластины локаций
  lightkeys/   световые ключи сцен (LS-KEY)
  screens/     экранные подложки «второй сцены» (без текста)
  keyframes/   утверждённые ключевые кадры шотов (вход i2v)
```

Первый фильм: `est-ideya/` («ЕСТЬ ИДЕЯ!», короткометражный 3D-мультфильм, 2026).
